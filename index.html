MedZone — Online Pharmacy & Delivery Platform

Final year project

Full-stack MERN platform · six user roles · React, Node.js, Express, MongoDB, Socket.IO

  • Built a six-role platform covering online ordering, an in-store point-of-sale system, multi-branch pharmacy management and end-to-end rider delivery logistics.
  • Implemented the full order lifecycle in Node.js/Express/MongoDB: atomic stock reservation so two customers can't buy the last box, Stripe checkout confirmed by signed webhook, and a rule-based order-status state machine.
  • Added real time with Socket.IO — live order updates, role-scoped chat, and a rider-tracking map using Leaflet with OSRM road routing, progress and ETA.
  • Designed a secure delivery handover: time-limited, rate-limited OTP codes with timing-safe verification, so an order is only marked delivered once the handover is proven.
  • Secured it with JWT in httpOnly cookies plus role- and ownership-based authorization middleware, and kept an append-only ledger for auditable weekly rider and pharmacy settlements.

Building now

Full-stack MERN application · personal project
